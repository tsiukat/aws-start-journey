## 👩‍💻 About This Repository

Welcome! This repository documents my structured hands-on experience and lab projects with **AWS Cloud** and its integration concepts within modern Enterprise/Salesforce ecosystems.

As a **Salesforce Consultant with a background in Business Analysis and Process Management**, I focus on understanding both functional configuration and underlying cloud infrastructure (Compute, Storage, Serverless, Security, and Voice/CTI integration services).

All lab exercises in this repository are structured by functional domain, containing step-by-step documentation, service configurations, and practical use cases.

---

## 🎯 Repository Structure & Completed Labs

The repository is organized into dedicated modules covering key AWS core services and integration scenarios:

- ⚙️ **Compute & Storage:** EC2 deployment, EBS volumes, S3 static hosting & bucket security
- ⚡ **Serverless & Automation:** AWS Lambda, CloudWatch monitoring, systems automation
- 🌐 **Networking & Security:** VPC configuration, subnets, IAM policies, CloudTrail auditing
- 🗣️ **Voice, AI & Integration Concepts:** Lab exploration of Amazon Polly, Lex, SageMaker basics, and voice integration patterns (e.g., CTI / Amazon Connect with Service Cloud)
- 🐍 **Scripting & Tooling:** Python automation basics, CLI operations, and deployment configurations
